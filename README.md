# CS 152 Lab 5

This repository contains the starter code for [CS 152 Lab 5](https://cs152.org/lab/lab5/).
Follow the lab specification for assignment instructions, implementation
requirements, and submission details.

The course website also provides these guides:

- [Setup](https://cs152.org/lab/lab5/setup/): connecting to your instance and preparing the lab environment.
- [Benchmarking](https://cs152.org/lab/lab5/resources/benchmarking/): running correctness checks, comparing saved experiments, and choosing workloads.
- [Program Guide](https://cs152.org/lab/lab5/resources/program-guide/): understanding the pipeline and running the application directly.
- [APerf](https://cs152.org/lab/lab5/resources/aperf/): collecting and viewing profiles.
